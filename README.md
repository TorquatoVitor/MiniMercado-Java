# Mini Market Management System

Simple Java application developed to practice the fundamentals of **Object-Oriented Programming (OOP)**.

The project simulates basic supermarket management operations such as product registration, stock listing, and interaction through a console menu.

## Features

- Product registration
- Product name, price, and stock quantity management
- Stock listing
- Currency formatting
- Interactive console menu
- Dynamic product storage

## Tech Stack

- Java
- Object-Oriented Programming
- Java Collections
- Console Application

## How to Run

Clone the repository:

```bash
git clone https://github.com/TorquatoVitor/MiniMercado-Java.git
```

Enter the project directory:

```bash
cd MiniMercado-Java
```

Open the project in an IDE such as:

- IntelliJ IDEA
- Eclipse
- VS Code

Run the main class:

```text
Principal.java
```

located in:

```text
br.com.mercado.main
```
