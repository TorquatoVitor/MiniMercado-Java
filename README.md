# 🛒 Sistema de Gestão de Mercado

Este é um projeto simples em **Java** desenvolvido para praticar os fundamentos da Programação Orientada a Objetos (POO).

## 🚀 Funcionalidades
- **Cadastro de Produtos**: Registo de nome, preço e quantidade em stock.
- **Listagem de Stock**: Visualização de todos os itens com formatação de moeda (R$).
- **Menu Interativo**: Interface via consola para facilitar o uso.

## 🛠️ Conceitos Praticados
- **Encapsulamento**: Uso de atributos `private` e métodos `getters`.
- **Coleções Dinâmicas**: Utilização de `ArrayList` para gerir os dados.
- **Interatividade**: Entrada de dados com a classe `Scanner`.
- **Organização**: Divisão do código em pacotes (`modelo`, `servico`, `main`).

## 📦 Como Executar
1. Clone este repositório.
2. Abra o projeto no Eclipse ou IntelliJ.
3. Execute a classe `Principal.java` localizada no pacote `br.com.mercado.main`.
